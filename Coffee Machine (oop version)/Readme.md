# ☕ Coffee Machine (OOP)

A simple coffee machine simulator built with Python using Object-Oriented Programming (OOP).

## Features

- Prepare three types of coffee:
  - Espresso
  - Latte
  - Cappuccino
- Check available resources
- Process coin payments
- Calculate and return change
- Display machine reports
- Turn the machine off with a command

- Object-Oriented Programming (OOP)

- Methods

- Importing modules
- Conditional statements
- Loops

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder:

```bash
cd Coffee-Machine
```

3. Run:

```bash
python main.py
```
